## 🎯 Temario y Ejes Conceptuales

El mapa desglosa los pilares de la programación en Java a través de tarjetas dinámicas con sintaxis y snippets en tiempo real:

1. **Estructura Básica de un Programa en Java**:
   - Función y firma del método \public static void main(String[] args)\.
   - Convenciones de nomenclatura de clases, paquetes y métodos.
2. **Tipos de Datos y Variables**:
   - Primitivos (\int\, \double\, \oolean\, \char\, etc.) vs Tipos Referenciados (\String\, Clases).
   - Inferencia de tipos local con \ar\.
3. **Operadores y Expresiones**:
   - Operadores aritméticos, relacionales y lógicos.
   - Precedencia y evaluación de expresiones.
4. **Estructuras de Control de Flujo**:
   - Sentencias condicionales (\if\, \if-else\, \switch\).
   - Bucles interactivos (\or\, \while\, \do-while\).
5. **Entrada y Salida estándar**:
   - Lectura de consola mediante \Scanner\.
   - Formateo de salida con \System.out.println()\ y \System.out.printf()\.

## 🛠️ Tecnologías Utilizadas

- **Frontend:** HTML5 semántico + JavaScript moderno.
- **Diseño & Estilos:** Tailwind CSS (vía CDN) con diseño responsivo, transiciones suaves y estética de tarjetas flotantes.
- **Tipografía:** Inter & monospace para bloques de código con fondo oscuro (\#1e293b\).
- **Despliegue:** GitHub Pages (automatizado desde la rama \main\).
