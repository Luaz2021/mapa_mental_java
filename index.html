📦

1. Variables e Identificadores

Las "cajas" donde guardamos datos

  • Variable: Espacio de memoria con un nombre
  • 3 Características:
    • Identificador (nombre único)
    • Tipo de dato (int, double, String...)
    • Valor (el dato guardado)
  • Reglas de nombres:
    • Empiezan con letra minúscula
    • Sin espacios (use camelCase)
    • Sin palabras reservadas
  • 🎯 Ejemplo: int edad = 18;
🔢

2. Tipos de Datos

8 tipos primitivos + String

  • Números enteros:
    • byte (muy pequeño)
    • short (pequeño)
    • int (normal) ⭐ Más usado
    • long (grande)
  • Números decimales:
    • float (precisión simple)
    • double (doble precisión) ⭐ Más usado
  • Otros:
    • boolean (true/false)
    • char (un carácter: 'A')
    • String (texto: "Hola") ⭐ Muy usado
🎬

3. Declaración e Inicialización

Cómo crear y usar variables

Declaración: Reservar espacio

int edad;

Inicialización: Dar valor inicial

edad = 18;

Ambas juntas:

int edad = 18;

Constantes: Valor que NO cambia

final double PI = 3.14;
⌨️

4. Scanner - Entrada de Datos

Pedir datos al usuario

1. Importar Scanner:

import java.util.Scanner;

2. Crear objeto Scanner:

Scanner sc = new Scanner(System.in);

3. Pedir datos:

String nombre = sc.nextLine();
int edad = sc.nextInt();
double nota = sc.nextDouble();

⚠️ Con decimales: usar coma (,) en consola, punto (.) en código

➕

5. Operadores

Hacer cálculos y comparaciones

  • Aritméticos: + - * / %
  • Asignación: = += -= *= /=
  • Incrementales: ++ --
  • Relacionales: > < >= <= == !=
  • Lógicos: && || !
  • Concatenación: + (para unir Strings)

Orden de precedencia:

() → ++/-- → */% → +/- → comparaciones → lógicos → asignación

🔄

6. Conversión de Tipos (Casting)

Cambiar de un tipo a otro

Implícito (automático):

De menor a mayor capacidad

int num = 100;
long numLargo = num; // Automático

Explícito (forzado):

De mayor a menor capacidad (puede perder datos)

double decimal = 9.8;
int entero = (int) decimal; // 9

String a número:

int num = Integer.parseInt("123");
double dec = Double.parseDouble("3.14");
🖥️

7. Salida por Pantalla

Mostrar resultados

System.out.print():

Imprime y el cursor queda en la misma línea

System.out.print("Hola");

System.out.println():

Imprime y salta a la siguiente línea

System.out.println("Hola");

Concatenar texto + variables:

String nombre = "Ana";
int edad = 20;
System.out.println("Hola " + nombre + ", tienes " + edad + " años");
💬

8. Comentarios

Documentar tu código

Una línea:

// Este es un comentario de una línea

Múltiples líneas:

/* Este es un comentario
de varias líneas */

Javadoc (documentación):

/** Documentación del programa
* @author Tu Nombre
* @version 1.0
*/

✅ Pueden valer hasta 1 punto en el examen

📝 Estructura Completa de un Programa Java

import java.util.Scanner;  // 0. Importar librerías

public class PrimerEjemplo {
    public static void main(String[] args) {
        
        // 1️⃣ CREACIÓN DE VARIABLES
        String nombre;
        int edad;
        double nota1, nota2, media;
        
        // 2️⃣ PETICIÓN DE DATOS
        Scanner sc = new Scanner(System.in);
        
        System.out.print("Dime tu nombre: ");
        nombre = sc.nextLine();
        
        System.out.print("Dime tu edad: ");
        edad = sc.nextInt();
        
        System.out.print("Nota 1er trimestre: ");
        nota1 = sc.nextDouble();
        
        System.out.print("Nota 2do trimestre: ");
        nota2 = sc.nextDouble();
        
        // 3️⃣ OPERACIONES
        media = (nota1 + nota2) / 2;
        
        // 4️⃣ RESULTADOS
        System.out.println("Hola " + nombre);
        System.out.println("Tu nota media es: " + media);
    }
}

⚡ Recordatorios del Profesor Javier

📌 Nombres de clases vs variables

• Clases: PrimerEjemplo (PascalCase)
• Variables: primerEjemplo (camelCase)
• Constantes: PRIMER_EJEMPLO (SCREAMING_SNAKE_CASE)

⚠️ Decimal: coma vs punto

• En código: double nota = 4.5; (punto)
• En consola: escribir 4,5 (coma)
• Si usas punto en consola → Excepción ❌

🎯 Orden en el programa

1. Creación de variables
2. Petición de datos
3. Operaciones
4. Resultados

💾 Guardar o no guardar

• Si necesitas el valor después → Variable
• Si solo lo muestras una vez → Directo en println()
Ejemplo: System.out.println((nota1+nota2)/2);
